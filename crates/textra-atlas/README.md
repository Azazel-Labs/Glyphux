# textra-atlas

Font atlas generation on top of [textra](../textra): charsets, glyph boxes, MaxRects / skyline
packing, parallel SDF / PSDF / MSDF / MTSDF / mask generation and JSON / CSV layouts in
[msdf-atlas-gen](https://github.com/Chlumsky/msdf-atlas-gen)'s format. See the workspace
[README](../../README.md) for details and the `textra-atlas` command line tool in `textra-cli`.
